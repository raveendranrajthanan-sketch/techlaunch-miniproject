# TechLaunch Mini Project Brief

## Project Goal

Build one responsive TechLaunch landing page that demonstrates the HTML, CSS, JavaScript, responsive design, accessibility, form validation, Git, and documentation skills covered during the four-week module.

## Required Sections

The page must contain these sections in this order:

1. Header / Navigation — `#top`
2. Hero — `#home`
3. About — `#about`
4. Categories — `#categories`
5. Services / Products — `#services`
6. Contact — `#contact`
7. Newsletter — `#newsletter`
8. Footer — `#footer`

## Responsive Requirements

The page should support:

- 320px, 375px, and 414px mobile widths
- 768px and 834px tablet widths
- 1024px, 1280px, and 1440px desktop widths
- Mobile-first design
- CSS Grid and Flexbox
- No horizontal scrolling
- 44px minimum touch targets

## Contact Form

The contact form requires client-side validation for:

- Name
- Email
- Phone
- Subject
- Message
- Consent checkbox

Validation should use the specified regular expressions and provide dynamic feedback after fields are touched.

## Images

The project requires at least three images with:

- Meaningful alt text
- Appropriate file sizes
- Own or openly licensed sources
- Credits recorded in the README

## Technology Restrictions

Allowed:

- HTML5
- CSS3
- Vanilla JavaScript
- Flexbox
- CSS Grid
- VS Code
- Chrome DevTools
- Git and GitHub

Not allowed:

- React
- Vue
- Bootstrap
- Tailwind
- jQuery
- Backend/database
- Build tools or preprocessors
- Additional HTML pages
- Table-based layouts

## Git Requirements

The project should have meaningful incremental commits using clear imperative commit messages under 60 characters.

## Documentation

The project requires:

- `README.md`
- `PROMPTS.md`
- `docs/TEST-LOG.md`
- `docs/BRIEF.md`

## Deployment

The final project should be deployed using GitHub Pages from the repository root.

## Limitations

Contact and newsletter forms are client-side demonstrations only. They do not send real emails or store submitted data.


# TechLaunch – Project Brief

## Project Overview
TechLaunch is a school project website designed to help students learn about web development, programming, digital skills, and technology.

## Main Features
- Responsive website layout for mobile, tablet, and desktop.
- Services section with service cards and Learn More buttons.
- About section with additional information and Show More functionality.
- Contact form with input validation.
- Newsletter form with validation.
- Mobile navigation menu.
- Interactive image toggle functionality.
- Scroll-reveal animations with reduced-motion support.

## Design Improvements
- Improved typography, spacing, and visual appearance.
- Enhanced service cards and button styling.
- Improved responsive layouts across different screen sizes.
- Maintained the existing green and orange colour theme.
- Added accessibility and usability improvements.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Git and GitHub Pages

## Project Goal
To create a modern, user-friendly, accessible, and responsive website for students interested in learning technology and developing practical skills.
