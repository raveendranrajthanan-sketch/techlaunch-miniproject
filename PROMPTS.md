# AI Prompt Record

## Prompt 1 — Page Structure

**Prompt:**  
"Create a responsive landing page structure for a technology education website called TechLaunch using one HTML file and eight sections: header, hero, about, categories, services, contact, newsletter, and footer."

**Output:**  
The AI suggested a semantic HTML structure with the required sections and navigation links.

**Changes / Why:**  
The structure was reviewed and adjusted to match the coursework requirements and section IDs.

**Compliance:**  
Used one `index.html` file and semantic HTML5 elements.

## Prompt 2 — Responsive CSS

**Prompt:**  
"Create a mobile-first responsive CSS design for the TechLaunch landing page using CSS Grid and Flexbox with breakpoints at 768px and 1024px."

**Output:**  
The AI produced responsive layouts for mobile, tablet, and desktop screen sizes.

**Changes / Why:**  
Spacing, colours, card sizes, and image dimensions were adjusted to match the project design.

**Compliance:**  
Used CSS3, Flexbox, CSS Grid, and the required responsive breakpoints.

## Prompt 3 — Contact Form Validation

**Prompt:**  
"Create JavaScript client-side validation for a contact form using one validation rules data structure and one generic validation function."

**Output:**  
The AI suggested regex-based validation for name, email, phone, subject, message, and consent.

**Changes / Why:**  
The validation rules were checked against the coursework requirements and implemented in `script.js`.

**Compliance:**  
Validation is client-side only and does not provide server-side security.

## Prompt 4 — Rejected AI Output

**Prompt:**  
"Create a contact form using a JavaScript library such as jQuery for validation."

**Output:**  
The AI suggested using jQuery for form validation.

**Changes / Why:**  
The suggestion was rejected because the coursework only allows vanilla JavaScript and does not allow jQuery.

**Compliance:**  
Rejected technology was not used. The final implementation uses vanilla JavaScript.

## Prompt 5 — Rejected AI Output

**Prompt:**  
"Create the TechLaunch website using Bootstrap components and a responsive Bootstrap grid."

**Output:**  
The AI suggested using Bootstrap classes and components.

**Changes / Why:**  
The output was rejected because Bootstrap is not allowed by the coursework requirements. The layout was implemented using CSS Grid and Flexbox instead.

**Compliance:**  
No Bootstrap or external UI framework was used.

## Prompt 6 — Image and Content Improvement

**Prompt:**  
"Improve the TechLaunch landing page content so it clearly describes technology learning, web development, programming, UI/UX design, and digital skills."

**Output:**  
The AI suggested clearer educational content for the About, Categories, and Services sections.

**Changes / Why:**  
The content was reviewed and edited to keep it relevant to the TechLaunch project.

**Compliance:**
